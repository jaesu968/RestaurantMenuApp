Description

Along with the title, we should display menu items. Let's start simple by adding a single item beneath the title. Then make it obvious the title isn't just another item, use styling and positioning to clearly distinguish it from the menu items.

Objectives

  1. Make the existing title appear centered with a text size of 48sp.

  2. Create a new composable, MenuItem, that contains a Text displaying "Fettuccine".

  3. Align MenuItem at the start with a text size of 24sp.

  4. Place MenuItem below the title.
