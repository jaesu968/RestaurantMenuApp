Description

The MenuItem composable is functional, but the menu should include multiple items instead of just "Fettuccine". Display a list of MenuItem composables showing all available recipes.

Each MenuItem must manage its own state, including its specific stock and ordered amount, applying the same constraints implemented previously.

Objectives

  1. Each MenuItem should have a recipe name, a "+", an order amount, and a "-" just like the existing "Fettuccine" menu item.

  2. Use the following data mapping recipe names to stock amounts:

    val recipesNameToStockAmount = mapOf(
    "Fettuccine" to 5,
    "Risotto" to 6,
    "Gnocchi" to 4,
    "Spaghetti" to 3,
    "Lasagna" to 5,
    "Steak Parmigiana" to 2
)

  3. Create one MenuItem for each recipe in the map.

  4. Ensure each MenuItem:

    • Maintains its own amountOrdered.

    • Uses its corresponding amountStock.

    • Applies ordering limits independently.

  5. Display all recipes as a list of MenuItem.
