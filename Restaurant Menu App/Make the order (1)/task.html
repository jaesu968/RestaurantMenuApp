Description

Waiters can adjust order quantities for each menu item, but there is currently no way to submit the order. Introduce a button to register orders, provide visual feedback with a summary, and update stock accordingly.

Objectives

  1. Add a Button with:

    • Black background color.

    • White content color.

    • Inside it, a Text displaying "Make Order" with a font size of 24sp.

  2. Add an onClick listener to the button to handle order registration.

    • If the button is clicked when all order quantities are 0, do nothing.

    • If the button is clicked and only one item's quantity is greater than 0, show a toast with the format "Ordered:\n==> ${recipeName}: $orderAmount" and update the stock for that item.

    • If the button is clicked and multiple items have a quantity greater than 0, show a toast in the same format as above with an additional line for each item using the same recipe line format, and update the stock of each ordered item:

      Ordered
==> ${recipeName1}: $orderAmount1
==> ${recipeName2}: $orderAmount2
...

  3. After an order is made:

    • Decrease the stock based on ordered quantities.

    • Ensure ordering limits and visual cues reflect the updated stock.

    • Reset all ordered amount to 0 to prepare for new orders.
