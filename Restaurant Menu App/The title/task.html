Description

Some applications serve as tools for staff. For example, one might assist waiters by helping them send orders to the kitchen while ensuring they don't request items that are out of stock.

Our first task is pretty straightforward: display a title on the screen.

Objectives

  1. Display a title on the screen with the text "Orders Menu".

  2. Test will, on purpose, check for exact matches on all required text in this project. Make sure there are no extra or unintended whitespaces in any of the strings.

Remember to verify that the project is configured according to the following instruction: Configure project and Gradle JDK.
