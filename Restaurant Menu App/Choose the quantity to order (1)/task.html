Description

Listing menu items alone isn't enough. Waiters should be able to adjust the amount ordered for each menu item, while staying within the available stock to avoid impossible orders.

Let's improve the MenuItem composable to allow increasing and decreasing the ordered quantity, while displaying the current amount. When the ordered amount reaches the stock limit, change the item text color to red.

Objectives

  1. Take amountOrdered as the quantity selected for a menu item. Its initial value is 0.

  2. Take amountStock as the available stock for a menu item. The initial amountStock for "Fettuccine" is 5.

  3. Add a Text displaying "+" on the same row as "Fettuccine". Make it clickable, increasing amountOrdered when clicked.

  4. Add a Text on the same row displaying the current value of amountOrdered.

  5. Add a Text displaying "-" on the same row. Make it clickable decreasing amountOrdered when clicked.

  6. Ensure amountOrdered never goes below 0 or above amountStock.

  7. If amountOrdered is less than amountStock, display "Fettuccine" in black.

  8. If amountOrdered is equal to amountStock, display "Fettuccine" in red.

obs: dark mode is intentionally ignored for this task.
